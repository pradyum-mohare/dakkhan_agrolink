# Dakkhan Agrolink

Lightweight React + Vite website with:
- Home
- Products
- Contact
- Sugar catalog with S 30, S 31, M 30, M 31, L 30, L 31
- Original lightweight SVG grade visuals
- Google Form placeholder for ordering

The SVG product visuals are original illustrative graphics, not photographs of a particular supplier's stock. Replace them with your own product photographs if desired.

## Run locally

```bash
npm install
npm run dev
```

Replace `https://forms.google.com/` in `src/pages/Products.jsx` with your actual Google Form URL.
